# 🏥 Insurance Data Analysis — Power BI

## 📊 Project Overview

This project is an **Insurance Data Analysis Dashboard** developed using **Microsoft Power BI** to analyze insurance policy, customer, claim, premium, and coverage-related data.

The dashboard transforms raw insurance data into interactive and meaningful business insights, helping understand **policy performance, claim trends, customer demographics, premium distribution, and insurance coverage patterns**.

The project demonstrates an end-to-end Power BI workflow, including:

* Data loading and preparation
* Data cleaning using Power Query
* Data transformation
* Data modeling
* DAX calculations
* Interactive dashboard development
* Business-oriented data analysis

---

## 🎯 Business Objectives

The main objectives of this project are to:

* Analyze the overall insurance portfolio.
* Understand the distribution of insurance policies.
* Analyze total premiums collected.
* Evaluate claim amounts and claim trends.
* Identify customer demographic patterns.
* Compare different insurance policy types.
* Analyze coverage and premium distribution.
* Identify important trends and patterns using interactive dashboards.

# 📂 Dataset

The project uses an insurance dataset containing information related to customers, policies, premiums, claims, and other insurance attributes.

### Important Fields

Some of the major fields used in the analysis include:

* Policy information
* Customer information
* Age
* Gender
* Policy Type
* Premium Amount
* Coverage Amount
* Claim Amount
* Claim-related attributes
* Policy status
* Customer-related attributes

The raw dataset was first imported into **Power BI** and then prepared using **Power Query** before being used for visualization and analysis.

---

# 🔄 Data Preparation & Transformation

The raw dataset required preprocessing before analysis.

The following transformations were performed in **Power Query**:

### 1. Data Cleaning

* Removed unnecessary columns.
* Checked and handled missing values.
* Corrected data types.
* Removed duplicate records where required.
* Standardized column values.

### 2. Data Transformation

* Renamed columns for better readability.
* Converted numerical fields into appropriate data types.
* Converted date fields into proper date formats.
* Prepared categorical fields for analysis.
* Created/derived fields required for dashboard analysis.

### 3. Data Validation

The transformed dataset was reviewed to ensure that:

* Numerical values were correctly formatted.
* Categories were consistent.
* Dates were correctly recognized.
* The dataset was suitable for analysis and visualization.

---

# 🧮 Data Modeling & DAX

After data preparation, the transformed data was loaded into the Power BI data model.

DAX was used to create analytical measures required for the dashboard.

Examples of analytical metrics include:

* **Total Policies**
* **Total Premium**
* **Total Coverage**
* **Total Claims**
* **Average Premium**
* **Average Claim Amount**
* **Claim-related metrics**

These measures allow the dashboard to dynamically respond to user selections and filters.

# 🎛️ Interactive Filters

The dashboard includes interactive filters/slicers that allow users to dynamically explore the data.

Users can filter the analysis based on relevant insurance and customer attributes.

Examples include:

* **Policy Type**
* **Gender**
* **Age / Age Group**
* **Policy Status**
* Other available categorical attributes

When a filter is selected, the dashboard visuals and KPIs update dynamically.

This makes the dashboard useful for **interactive business analysis rather than static reporting**.
